# More realistic tyre rubber

## Changes
- Replace the tyre and raised tread with physically based rubber materials using roughly 0.75 roughness, zero metalness, stronger normal detail, and restrained rubber reflections.
- Refine the tyre cross-section into a gently convex sidewall with rounded shoulders.
- Add subtle molded concentric ridges near the rim and shoulder without restoring the removed square side blocks.
- Shape a short shoulder transition so the existing text tread visually wraps from the crown toward the sidewall.
- Replace the remote lighting preset with a local studio-light environment and tune rendering for stronger highlights and deep shadows.

## Validation
- Check the portrait mobile and desktop previews for full framing, correct materials, working controls, and clean runtime output.
